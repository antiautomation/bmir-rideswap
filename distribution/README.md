# BMIR Rideswap - Distribution

This is the complete BMIR Rideswap application ready for deployment.

## 🚀 Quick Start

### Local Usage (ChromeBook, etc.)
Simply open `index.html` in your web browser. The application will work locally without needing a server.

### Web Server Deployment
Upload all files in this directory to your web server root directory.

## 📁 Files Included

- `index.html` - Main application
- `app.js` - Application logic
- `styles.css` - Stylesheets
- `config.js` - Firebase configuration
- `manifest.json` - PWA manifest
- `sw.js` - Service worker
- `logo.png` - Application logo
- `firestore.rules` - Database security rules
- `firestore.indexes.json` - Database indexes
- `.htaccess` - Server configuration
- `LICENSE` - License information

## ⚙️ Configuration

Before using, update `config.js` with your Firebase project settings.

## 🔧 Deployment

1. **Local**: Open `index.html` in any modern browser
2. **Web Server**: Upload all files to your web server root
3. **Firebase**: Deploy Firestore rules using Firebase CLI
